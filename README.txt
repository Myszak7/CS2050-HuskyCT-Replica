During Milestone 2 we focused on adding to our main husky.py file from Milestone 1. We implemented a LinkedQueue structure for 
a waitlist of EnrollmentRecord objects. Student objects inside of the EnrollmentRecord objects would be added to the waitlist for
a given course if the course was at full capacity. We also implemented recursive binary search, and bubble sort/insertion sort
using different keys. New methods for the Course class were also added related to adding/dropping students from the waitlist.

Demos of our project handling data read in from the csv files can be found in a seperate file called 'demo_milestone2.py'.
